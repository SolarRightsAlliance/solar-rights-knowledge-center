# Solar Rights Knowledge Center

A human-first WordPress search and editorial analytics plugin for Solar Rights Alliance.

## Principles

- Real people, real answers, no public-facing chatbot.
- Curated category-restricted search.
- Privacy-conscious analytics: no IP addresses, names, emails, user accounts, cookies, or personal browsing histories.
- WordPress-native APIs, output escaping, input validation, nonce checks, query limits, and short-lived caching.

## Shortcode

```text
[sra_search category="consumer-guide" placeholder="Search the Consumer Guide..."]
```

## Admin

After activation, use **Knowledge Center → Analytics** and **Knowledge Center → Settings**.

## Development

The installable plugin is the `solar-rights-search` directory. Create a release ZIP whose top-level directory is `solar-rights-search`.
