Human-first category-restricted live search with privacy-conscious editorial analytics.

== Description ==
Provides a reusable live-search shortcode, synonym-aware ranking, highlighted matches, keyboard navigation, and an analytics dashboard designed to identify content needs without tracking personal information.

== Installation ==
1. Upload and activate the plugin.
2. Add [sra_search category="consumer-guide" placeholder="Search the Consumer Guide..."] to an Elementor Shortcode widget.
3. Review Knowledge Center → Settings.
4. View reports under Knowledge Center → Analytics.
